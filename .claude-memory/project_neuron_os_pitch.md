## Product Rename
- mentor-ai → **Neuron OS**
- Positioning: "Digitalni operativni sistem koji uči tvoj biznis i ubrzava sve što radiš"
- NOT "autonomous business" (too broad) — contextual business accelerator

## Key Architecture Decision: n8n Integration (2026-04-01)
- OpenClaw designs and executes ALL processes through n8n workflows
- OpenClaw proactively discovers automatable processes
- n8n becomes execution layer (400+ integrations), not a competitor
- This makes "unlimited processes" for Enterprise sustainable — agent builds, not our team
- **Why:** Solves the scalability problem with custom process development
- **How to apply:** All process automation should be designed as n8n workflows orchestrated by OpenClaw

## Business Model
- Setup fee: Free (Starter), 1,000 EUR (Pro), 2,000 EUR (Enterprise)
- Subscription: 299/799/2,499 EUR per month
- Custom processes: 125-150 EUR/hour
- Process catalog grows as n8n workflows (reusable across clients)
- Revenue streams: Setup + Subscription + Custom process dev

## Target Market
- Digital-native service companies (5-50 employees) — agencies, SaaS, e-commerce, consulting
- USA market first
- Industry agnostic but starting with firms already spending on AI tools
- Buyer AND user: business owner

## Investment Ask
- Minimum: 480,000 EUR (300K dev + 80K infra + 70K GTM + 30K buffer)
- Minimum investor ticket: 40,000 EUR
- Team: 3 founders + hire architect, 2 engineers, part-time designer
- Break-even: ~50-60 clients, 10-14 months from launch

## Key Differentiator
"Zapier/n8n su ruke bez mozga. Copilot/Notion su mozak bez ruku. Neuron OS je mozak koji SAM koristi n8n kao ruke — sa vlasnikom kao kontrolorom."

## Competitive Positioning
- Builder tools (Zapier, n8n, Make): reactive, user must design
- Copilots (MS Copilot, Notion AI): siloed in own ecosystem
- Agent platforms (Relevance AI, Lindy): still manual agent creation
- Neuron OS: learns business + proactively discovers + executes via n8n + human approval gates
